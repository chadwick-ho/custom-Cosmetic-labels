# Custom Bottle Labels Manufacturer

Static multi-page B2B inquiry website for a custom bottle labels manufacturer.

## Website Description

This website is designed for overseas B2B packaging buyers who need custom cosmetic bottle labels and custom supplement bottle labels. Visitors can contact the sales team by WhatsApp, email, upload artwork, or submit the quote form.

## Core Products

- Custom Cosmetic Bottle Labels
- Custom Supplement Bottle Labels

## How to Update Images

Replace files in ssets/images/ with optimized WebP files using the same lowercase hyphenated filenames, then commit the updated files to the main branch.

## How to Update WhatsApp Number

Search for YOURNUMBER in the HTML files and replace it with the real WhatsApp number in international format, without plus signs or spaces.

## How to Update Email Address

Search for sales@yourdomain.com in the HTML files and replace it with the active sales email address.

## How to Add a Custom Domain Later

Add the custom domain in GitHub repository Settings > Pages. Then create the required DNS records with the domain provider and optionally add a CNAME file containing the domain name.
